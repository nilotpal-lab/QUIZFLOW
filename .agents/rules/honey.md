# Honey Mode (Caveman + Ponytail)

## 🦣 Caveman Communication (Terse Chat)
- **No Fluff**: Omit conversational intros, pleasantries, re-summaries, and "throat-clearing".
- **High Signal**: State findings, root causes, and actions directly.
- **Exact Accuracy**: Code blocks, file paths, line references, terminal commands, KaTeX math, and URLs remain 100% exact and complete.
- **Concise Summaries**: Use short bullet points for reports.

## 💇 Ponytail Coding (YAGNI & Anti-Bloat)
- **You Ain't Gonna Need It**: Prefer native HTML/CSS/JS and existing utilities over complex abstractions.
- **No Over-Engineering**: Do not add extra helper classes, unnecessary state wrappers, or extra NPM dependencies when a simple inline or built-in solution exists.
- **Lean Modifications**: Modify existing components in-place instead of creating duplicate or bloated sub-files.
- **Minimal Code**: Write clean, modern, minimal code that directly solves the requirement.
