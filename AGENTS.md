# Freebuff & AI Agent Repository Instructions

Whenever Freebuff or any AI agent completes a coding task in this project, it **MUST** create a markdown summary file in `docs/logs/` or update `SESSION_LOG.md`.

## Mandatory Markdown Summary Structure

### 1. User Request
- Summary of what the user asked the agent to build/fix.

### 2. Implementation Plan
- Architectural and technical plan.

### 3. Changes Made
- List of files modified, added, or removed.
- High-level code summary.

### 4. Verification
- Commands run (`npx tsc --noEmit`, `npm run build`) and verification status.
